# 연우 전투 대기: 무심하고 졸린 관찰자

2026-11-16. 과장된 발끝 반복 대신 귀찮음·졸림·따분함·냉철함·가끔 허당이라는 성격을 기준으로 대기 연기를 다시 구성했다. 기존 전투 원화의 얼굴, 체형, 검정/파랑 의상과 분홍 장식을 기준으로 내장 이미지 생성 도구로 제작했다.

기본 대기는 6.8초 주기다. 발을 딛고 느리게 숨을 쉬며 무게를 조금 옮긴다. 대부분의 시간은 적을 바라보는 차분한 자세이며, 주기 끝에 눈꺼풀을 천천히 닫았다 뜬다. 전신을 흔들거나 반복해서 발을 까딱이는 변형은 사용하지 않는다.

공동 대기 연출 순서는 추흔과 번갈아 유지한다. 첫 대기 연출까지 7초, 연출 사이에는 최소 6초의 여유를 둔다. 연우는 입을 작게 가리고 하품한다. 연우의 세 번째 대기 연출마다 하품 대신 발에 걸린 사슬을 보고 살짝 빼낸 뒤 무심하게 자세를 되찾는다. 계속 기다리면 연우의 연출은 약 17초 간격, 사슬 정리는 약 50초 간격으로 나온다. 행동을 선택하면 대기 연출은 즉시 중단되므로 실제 간격은 달라진다. 사슬을 든 손은 모든 대기 프레임에서 동일하다.

미리보기는 평상시 한 주기와 하품·사슬 정리를 연속해서 보여 주기 위해 연출 사이의 대기 시간만 줄였다. 각 동작은 실제 속도다. 게임에서는 위의 긴 간격을 사용한다.

공격·수비·피격·특수기와 추흔 및 필드 체인은 유지한다. 이전 발끝 대기 자산은 보관하지만 게임에서는 사용하지 않는다. 검사 항목은 새 자산 연결, 포즈 잘림, 지지하는 발의 바닥 위치, 차분한 자세와 눈 깜빡임의 시간 비율, 드문 사슬 정리의 배치, 행동에 의한 중단이다.
