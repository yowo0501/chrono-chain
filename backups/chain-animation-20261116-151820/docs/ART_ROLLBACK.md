# 그림체 부분 복원 — 2026-11-16

새로 생성한 필드·전투 스프라이트와 스탠딩이 기존 게임과 어울리지 않는다는 피드백에 따라 **바로 직전에 사용하던 원본 그림과 크기**로 복원했다. `assets/characters/duo/`의 파일은 삭제하지 않았지만 실행 코드에서는 더 이상 사용하지 않는다.

현재 필드는 `assets/sprites/field/chuheun_night.png`, `yeonwoo_night.png`다. 전투의 대기·공격·기지개·하품·피격·집중·타이머·어쌔신·회복도 `assets/sprites/battle/`의 직전 그림과 모션을 사용한다. 새 대형 스탠딩을 제거하고 프롤로그의 이전 대사창 배치와 전투 초상을 복원했다.

두 명 파티, 초반 1~2 / 후반 2~3마리 조우, 조정한 적 수치, 16개 구역·30개 연결로의 새 맵은 유지한다. 이동은 8방향이며 속도 보정·모서리 충돌도 유지한다. 원본 그림은 4방향 3프레임이므로 대각선에는 해당 좌우 방향을 연결한다. 새로운 대각선 전용 그림은 이번 복원에 포함하지 않는다.

## 필드 체인

- 사거리: 3칸 → **4칸**. 대각선도 같은 실제 거리이며 벽을 통과하지 않는다.
- 모션: 0.2초 → **1초**. 0~0.45초 준비, 0.45~0.8초 방출, 0.8~1초 회수.
- 후딜: 0.8초 → **0.25초**. 빗나가면 총 1.25초 뒤 다시 이동·공격할 수 있다.
- 준비 구간에는 적을 타격하지 않는다. 느린 프레임에서도 방출 구간의 타격을 놓치지 않는다.
- 기존 전신 프레임을 통째로 뒤로 당기고 앞으로 내밀며 체인 궤적을 연결한다. 머리·몸통을 분할하지 않는다.
- 이동 중 T 입력 예약, 명중 시 아군 선제권, 전투 전환의 1초 대기는 유지한다.

`field_gimmicks_test`는 4칸 명중·5칸 제외·대각선 범위·벽 차단·준비 중 미타격·1.25초 잠금·입력 예약·선제권을 검사한다. `duo_overhaul_test`는 시스템 변경 유지와 원본 아트 경로 연결을 검사한다. 현재 캡처는 `art-reviews/restored-art/`다.
