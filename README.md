# Chrono Chain

my dream jrpg

하트골드풍 도트 캐릭터와 완전한 2D 타일맵을 사용하는 JRPG.

## 엔진

Godot 4.7 (GDScript, GL Compatibility 렌더러)

## 폴더 구조

- `scenes/` — 씬 파일(.tscn)
- `scripts/` — GDScript 코드(.gd)
- `assets/sprites`, `assets/tilesets`, `assets/audio`, `assets/fonts` — 리소스
- `data/` — 캐릭터/아이템/적 등 게임 데이터 리소스
- `addons/` — 에디터 플러그인 (필요 시)

## 실행 방법

1. [Godot 4.7 Standard 빌드](https://godotengine.org/download/windows/) 설치 (C# 안 씀, .NET 빌드 불필요)
2. Godot 실행 → Import → 이 저장소 폴더의 `project.godot` 선택
3. 우측 상단 Play 버튼(F5) — 밤의 도시 분수 광장에서 시작한다.

## 현재 맵 시스템

방향키로 이동하고 **E**로 가까운 가로등을 조사한다. **M**으로 지도를 연다.
128×64칸의 밤 도시를 16개 불규칙한 가로등 에어리어로 구성했다. 분수 광장·빵집·상점 거리는 빛, 외곽 뒷골목·공터는 어둠에서 시작한다.
어둠 구역은 주기적으로 적을 내보낸다. 프로토타입에서는 가로등 파괴를 보류한다. 처음부터 켜진 등과 직접 밝힌 등 모두 계속 빛 구역으로 유지된다. 적의 이동·도주와 밝은 구역 순찰은 유지한다.
가로등 복구는 무료이며, 꺼진 등은 파란 빛으로 위치가 보인다. **모든 에어리어를 점등하면 분수 광장에 보스가 나타난다.**
일반 전투는 **3~5마리**, 보스는 1마리다. 어둠 속에서는 걸을 때 랜덤 전투가 반복된다. 수동으로 복구한 가로등은 다시 꺼지지 않는다.

세부 규칙과 조정값: [맵 시스템](docs/MAP_SYSTEM.md).

## 필드 그래픽

회전 없는 순수 2D 카메라와 정교한 야간 도트 배경을 사용한다. 분수, 빵집 간판, 상점 차양, 주택, 창고, 강변과 골목으로 장소를 구분한다.
필드 캐릭터는 64px 고정 프레임으로 세부 묘사를 높였고, 추흔은 입을 다문 작은 미소다. 0.24초 이동과 한 칸마다 번갈아 내딛는 발은 유지한다.
화단과 임의 캐릭터 대사는 없다. 구성과 자산 경로는 [필드 아트](docs/FIELD_ART.md)를 참고한다.

## 4인 파티와 전투 규칙 (2026-10-21)

강추흔 → 김연우 → 강설아 → 장위성 순으로 행동한다. 필드에서는 네 명이 한 칸씩 앞사람을 따라 걷는다.
강설아는 방패 전개(수비 2: 공격 유도, 다음 한 차례 자동 수비, 스택 획득 없음)와 크게 휘두르기(집중 1: 위치 QTE 단일 강공격)를 사용한다.
장위성은 맵 밝히기(집중 2)로 현재 전투를 20초간 밝히고, 바인드(공격 1·집중 1)로 위치 QTE에 성공한 적의 행동을 2턴 봉쇄한다. 보스는 3왕복 모두 성공해야 한다. 캐릭터 설정·원화·초기 수치는 [파티 확장 기록](docs/PARTY_EXPANSION.md)에 정리했다.

적의 위·아래 위치에 맞춰 QTE 판정선이 왼쪽·오른쪽으로 이동한다. 수비도 공격자의 위치선을 맞춘다. 어둠은 적과 아직 성공한 적 없는 판정선을 숨기지만, 한 번 성공한 적의 판정선은 해당 전투 동안 계속 보인다.
타이머는 QTE 없는 전체 공격과 20초 밝힘, 벼락은 작은 전체 공격과 10초 밝힘이다.
어쌔신 스텝은 위치를 맞추는 4회 QTE, 회복은 아군 선택 후 음료수·샌드위치 동작이다.
보스는 밝게 시작해 전투 중 어두워지고 위치를 바꾼다. 전투 후 스택은 유지하며, 공격·수비·집중 각각 최대 3개다.
자세한 비용·초기 조정값·검사 방법은 [전투 문서](docs/BATTLE.md)를 참고한다.

스킬 사용 중 임의의 대사는 넣지 않는다. 설아는 말없이 앞으로 나와 방패를 전개하고, 종료되면 체인을 들고 원래 자리로 돌아간다.
