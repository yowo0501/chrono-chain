# Chrono Chain

my dream jrpg

강추흔·김연우 두 명으로 진행하는 8방향 2D 도트 JRPG.

## 엔진

Godot 4.7 (GDScript, GL Compatibility 렌더러)

## 폴더 구조

- `scenes/` — 씬 파일(.tscn)
- `scripts/` — GDScript 코드(.gd)
- `assets/sprites`, `assets/tilesets`, `assets/audio`, `assets/fonts` — 리소스
- `data/` — 캐릭터/아이템/적 등 게임 데이터 리소스
- `addons/` — 에디터 플러그인 (필요 시)

## 실행 방법

1. [Godot 4.7 Standard 빌드](https://godotengine.org/download/windows/) 설치 (C# 안 씀, .NET 빌드 불필요)
2. Godot 실행 → Import → 이 저장소 폴더의 `project.godot` 선택
3. 우측 상단 Play 버튼(F5) — 로고와 **프롤로그 실행 / 튜토리얼 실행** 메뉴가 열린다.

## 프롤로그와 실행 메뉴

**프롤로그 실행**은 별도 이벤트 씬을 재생한다. 검은 화면의 독백, 밤 골목의 추흔·연우 대화, 괴물의 꿈틀거림, 시선 전환, 체인 전개와 돌진, 금속 충돌음과 암전, 마지막 로고까지 이어진다. 전투는 시작하지 않는다.

대사는 클릭·Enter·Space·Z로 진행한다. 출력 중 누르면 문장을 완성하고, 한 번 더 누르면 다음으로 넘어간다. 종료 화면에서 다시 보기 또는 메뉴로를 선택한다. **F10**은 프롤로그·튜토리얼·전투 중에도 메뉴로 돌아간다.

**튜토리얼 실행**은 기존 `scenes/main/main.tscn` 작업물을 처음부터 실행한다. 메뉴로 돌아갔다가 다시 시작하면 튜토리얼 안내와 파티 상태가 초기화된다.

원문 대사와 연출 데이터는 `data/prologue.json`, 새 이미지와 생성 프롬프트는 `assets/prologue/`에 있다. 구현 구조와 검사 방법은 [프롤로그 문서](docs/PROLOGUE.md)를 참고한다.

## 현재 맵 시스템

메뉴에서 튜토리얼 실행을 선택하면 기초 튜토리얼이 시작된다. 안내 중에는 필드와 전투 타이머가 멈추고, 강조된 버튼 또는 표시된 키로만 진행한다. 이동 → 빛 구역 전투 → 공격/수비 선택별 설명 → 2라운드 집중/특수 설명 → 첫 어둠 전투의 숨은 판정선 → 전투 복귀 후 가로등 → 모든 등 점등 후 보스 순으로 안내한다. 집중/특수 설명 확인 후에는 원하는 행동을 자유롭게 선택한다. 설명은 실행 중 한 번씩 표시되며, 게임을 다시 실행하면 처음부터 안내한다. 아직 사용하지 않은 행동 설명은 이후 처음 선택할 때 표시한다.

튜토리얼 회귀 검사: Godot `--headless --path . --script tests/tutorial_test.gd`.

보스를 처치하면 자동으로 **튜토리얼 클리어** 안내가 뜨고 전투 재진입이 차단된다. **타이틀 화면으로 돌아가기** 버튼으로 메뉴에 복귀하며, 다시 실행하면 새 튜토리얼을 시작한다. 완료·복귀 회귀 검사: `tests/tutorial_clear_test.gd`.

방향키로 8방향 이동하고 **Shift**로 달린다. **T**로 체인을 휘두르고, **E**로 가까운 가로등을 조사한다. **M**으로 지도를 연다. 대각선 속도는 직선과 같고 건물 모서리를 통과할 수 없다.
128×64칸의 밤 도시를 16개 불규칙한 가로등 에어리어로 구성했다. 분수 광장·빵집·상점 거리는 빛, 서쪽 뒷골목·빵집 뒤 골목·북쪽 뒷골목·동쪽 굽은 골목만 어둠에서 시작한다.
어둠 구역은 주기적으로 적을 내보낸다. 프로토타입에서는 가로등 파괴를 보류한다. 처음부터 켜진 등과 직접 밝힌 등 모두 계속 빛 구역으로 유지된다. 적의 이동·도주와 밝은 구역 순찰은 유지한다.
가로등 복구는 무료이며, 꺼진 등은 파란 빛으로 위치가 보인다. **모든 에어리어를 점등하면 분수 광장에 보스가 나타난다.**
시험 버전은 어둠 구역 4개에서 시작한다. 일반 전투는 **1~2마리**, 꺼진 가로등 구역이 **2개 이하**로 남으면 **2~3마리**, 보스는 1마리다. 어둠 속에서는 걸을 때 랜덤 전투가 반복된다. 수동으로 복구한 가로등은 다시 꺼지지 않는다.

세부 규칙과 조정값: [맵 시스템](docs/MAP_SYSTEM.md).

## 필드 그래픽

2026-11-16 외형 부분 롤백: 직전에 사용하던 작은 SD 필드 도트와 기존 전투 아틀라스·특수기 모션·초상을 복원했다. 새로 생성했던 `assets/characters/duo/` 원화는 보관만 하며 현재 게임에서 참조하지 않는다. 추가했던 대형 캐릭터 스탠딩도 제거하고 이전 대사창 배치로 돌아갔다.

두 명 파티, 적 밸런스, 새 도시와 대각선 이동은 유지한다. 필드 그림은 기존 4방향·방향별 3프레임을 사용하며 대각선에는 해당 좌우 방향을 연결한다. 머리와 몸통은 분리하지 않는다. 새 8방향 원화의 그림체는 채택하지 않았다.

**필드 체인:** 사거리 4칸, 모션 0.5초, 후딜 0.25초. 전용 도트 24프레임으로 팔을 당긴 뒤 휘두르고 회수하며, 손목의 사슬에 긴 궤적을 연결한다. 준비 구간에는 타격하지 않는다. 벽 차단과 선제공격 규칙은 유지한다. 현재 체인·연우 대기 검수 캡처는 `art-reviews/chain-swing/`, 부분 롤백 기록은 [그림체 복원](docs/ART_ROLLBACK.md), 이번 동작 변경은 [필드 체인과 연우 대기](docs/CHAIN_SWING.md)에 있다.

회전 없는 순수 2D 카메라와 정교한 야간 도트 배경을 사용한다. 분수, 빵집 간판, 상점 차양, 주택, 창고, 강변과 골목으로 장소를 구분한다.
필드 캐릭터는 64px 고정 프레임으로 세부 묘사를 높였고, 추흔은 입을 다문 작은 미소다. 0.24초 이동과 한 칸마다 번갈아 내딛는 발은 유지한다.
화단과 임의 캐릭터 대사는 없다. 구성과 자산 경로는 [필드 아트](docs/FIELD_ART.md)를 참고한다.

## 두 명 파티와 전투 규칙 (2026-11-16)

강추흔 → 김연우 → 적 순으로 행동한다. 필드에서는 연우가 추흔의 이전 칸을 따라 이동한다. 설아·위성은 현재 파티와 스킬 목록에서 제외했다. 이전 네 명 구성은 [과거 파티 확장 기록](docs/PARTY_EXPANSION.md)에 남겨 둔다.

적의 위·아래 위치에 맞춰 QTE 판정선이 왼쪽·오른쪽으로 이동한다. 수비도 공격자의 위치선을 맞춘다. 어둠은 적과 아직 성공한 적 없는 판정선을 숨기지만, 한 번 성공한 적의 판정선은 해당 전투 동안 계속 보인다.
타이머는 QTE 없는 전체 공격과 20초 밝힘, 벼락은 작은 전체 공격과 10초 밝힘이다.
어쌔신 스텝은 위치를 맞추는 4회 QTE, 회복은 아군 선택 후 음료수·샌드위치 동작이다.
보스는 밝게 시작해 전투 중 어두워지고 위치를 바꾼다. 전투 후 스택은 유지하며, 공격·수비·집중 각각 최대 3개다.
자세한 비용·초기 조정값·검사 방법은 [전투 문서](docs/BATTLE.md)를 참고한다.

스킬 사용 중 임의의 대사는 넣지 않는다. 추흔의 힘 있는 휘두르기·기지개와 연우의 절제된 손목 동작·하품·실패 시 민망한 반응은 복원한 기존 전투 포즈를 사용한다.
