Godot 등록 경로와 project.godot의 시작 씬에서 확인했다.
이전 누락 원인: 튜토리얼 main.tscn과 프롤로그 chase_field.gd가 서로 다른 에셋 경로를 사용했다.
이번에는 두 경로 모두 C 필드 에셋으로 연결했다. 시작 아래 맵 이동 테스트를 추가했다.
이동 테스트는 기존 128x64 튜토리얼 지형과 충돌 데이터를 그대로 사용한다.
대사/적/랜덤 전투/보스 진행은 비활성화, 가로등은 점등 상태로 시작한다.
방향키 이동, Shift 달리기, M 지도, F10 메뉴 복귀.

1. 복원 자료
reference/battle: 전투 관련 44개 파일 원본 보관. 캐릭터 설정 변경 전 검은 머리 원본 시트 포함.
reference/skill-sources: 보존되어 있던 집중/지원/타이머/암살 원본도 함께 수집. 시기별 의상 차이는 별도 확인 대상.
reference/code: 새 오버홀 전 백업의 전투 및 스킬 재생 코드.
reference/toe-idle: 연우의 발끝 대기 원본/수정본과 위치 보정 기록.
metadata/reference_hashes.json: 모든 참조 파일 해시.
metadata/recovered_manifest.json: 원본 크기, 프레임 영역, 불투명 실루엣 면적, 셀 경계 접촉 여부.
설정화 변경 전 검은 머리 원본 8종에서 87개 프레임/자세를 측정했다.
참조 폴더의 모든 파일이 같은 시기의 디자인인 것은 아니다. 파일별 역할을 manifest에 구분했다.
원본 래스터에는 뼈대 데이터가 없다. 자세와 표정은 이미지 그대로 보존하며, 관절 설명은 육안 분석이다.

2. 동작과 표현 기준
추흔 대기: 3x2 시트의 6프레임, 1.6초. 편하게 굽힌 무릎, 가슴 앞 한 손, 다른 손에 체인.
몸을 통째로 들썩이거나 머리를 하늘로 꺾지 않는다. 적 쪽을 보며 부드럽게 웃는 인상 유지.
프레임 지속 시간은 0.28 / 0.22 / 0.30 / 0.28 / 0.22 / 0.30초.
추흔 준비: 4x4 motion 시트의 8~13번, 초당 5프레임. 팔을 머리 위로 들고 수평 타원 체인 회전.
연우 대기: 0→1→2→1→0, 1.8초. 상체는 얌전하게, 발끝만 작게 움직인다. 높은 발 들기 제외.
연우 준비: 몸통/머리/지지발은 고정, 손목만 ±0.12라디안 회전. 체인은 뒤쪽 세로 타원, 1.6초.
공격: 0→2→3→4→6→7, 총 0.8초. 준비/방출/신장/회수/정착 순서를 그대로 쓴다.
0.10~0.20초 체인 신장, 0.40~0.54초 회수. 체인의 시작점은 새 시트에서 다시 등록했다.
추흔의 쉬는 표현은 기지개와 편한 미소. 연우의 일반 대기에는 하품/큰 고개 움직임을 끼워 넣지 않는다.
집중은 4프레임/1초. 타이머·암살·지원 스킬은 기존 전용 시트의 재생 방식으로 복원했다.
상세 숫자는 metadata/animation_contract.json, 스킬별 전체 단계는 reference/code에 있다.

3. 새 디자인 적용
source: 예전 자세 시트를 직접 편집해 만든 새 원본 8종. 내장 이미지 생성 도구 사용.
추흔: 회색 머리, 호박색 눈, 검정/코발트 도복, 검은 허리띠, 주황 속옷과 운동화.
연우: 검정 긴 머리, 금색 머리핀, 호박색 눈, 검정/코발트 도복과 치마, 검정 부츠.
runtime: 대기·준비·공격/회수·방어/피격/표정과 연우 손목 분리 이미지.
기본 768x480 셀에 저장하고 기존 화면 배율로 표시한다. 작은 도트로 강제 축소하지 않는다.
원본의 투명 여백을 찾아 분할하여 발이나 체인이 셀 경계에서 잘리지 않도록 했다.
프레임별 몸 비율을 늘이거나 줄이지 않고, 시트 공통 배율과 지면 정렬만 적용했다.
추흔 오른쪽 아래 / 연우 왼쪽 위 배치는 유지했다.
새로 없던 스킬 애니메이션은 추가하지 않았다. 기존 스킬의 타이밍/시트 재생부터 복원했다.
생성 편집은 원본 자세를 따르지만 실루엣이 수학적으로 완전히 동일한 복제는 아니다.
최종 미술 확정 전 review의 연속 프레임으로 동작을 비교할 수 있다.

4. 필드 해상도
걷기 셀 64→320, 체인 셀 96→512. 원본에서 다시 추출하여 디테일을 유지한다.
화면의 캐릭터 비율은 C 기준을 유지한다. 건물은 원본 크기, 바닥은 504x504 텍스처를 사용한다.
맵 충돌/길/오브젝트 배치는 변경하지 않았다. 어둠 영역의 기존 푸른 조명과 연속 경계도 유지한다.
