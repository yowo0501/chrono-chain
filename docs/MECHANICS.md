# 기본 JRPG 매커니즘 (v0.1)

레퍼런스: 패미컴/슈퍼패미컴 시절 드래곤퀘스트(1~6), 파이널판타지(1~6).
목표: RPG Maker류 쯔꾸르 게임과 같은 느낌의 "2D 필드 + 도트 캐릭터 4방향 이동"
기본 골격을 먼저 만들고, 그 위에 전투·대화·스토리 같은 독자 시스템을 얹는다.

이 문서는 v0.1(이번 단계)에서 실제로 구현하는 범위와, 의도적으로 나중으로 미룬
범위를 구분해서 적어둔다.

## 화면 / 좌표 기준

- 타일 크기: **16x16px** (FC/SFC 시대 JRPG 필드의 표준 그리드 단위)
- 베이스 해상도: **256x224** (SNES 표준 해상도로 변경 — 기존 320x180은 범용 인디
  기본값이라 4:3 시대극 감성과 안 맞아서 교체)
- 스케일링: `window/stretch/mode = viewport`, 정수 배율로 화면에 맞춰 확대
  (픽셀이 뭉개지지 않도록 `canvas_textures/default_texture_filter = 0`, nearest)

## 필드 이동 (이번 단계 구현)

- **그리드 스냅 이동**: 캐릭터는 항상 타일 중심에 위치하고, 방향키를 누르면
  정확히 한 칸(16px)만 이동한다. 자유 이동(픽셀 단위 아날로그 이동)은 쓰지 않음
  — DQ/FF/쯔꾸르 특유의 "칸 이동" 느낌을 위해서.
- 이동 소요 시간은 약 0.14초 tween. 이동 중에는 다음 입력을 버퍼링하지 않고
  현재 이동이 끝난 뒤에 다음 키를 받는다 (심플하게, 나중에 큐잉 추가 가능).
- 이동하려는 칸에 충돌 타일(건물벽 등)이 있으면 이동을 취소하고 그 자리에서
  방향만 바꾼다 (고전 JRPG의 "벽에 붙어서 방향 전환" 동작).
- 4방향(상하좌우) 각각 걷기 애니메이션 2프레임(제자리/전진) + 정지 시 마지막
  방향을 바라보고 정지 프레임 유지.
- 카메라는 플레이어를 즉시 따라가되(스냅, lerp 없음 — 고전 타일 게임 느낌),
  맵 경계 밖으로는 나가지 않도록 clamp.

## 캐릭터 사양

- 스프라이트 크기 16x16px, 4방향 x 2프레임 = 8프레임 스프라이트시트
- SFC 시대 팔레트 감성: 캐릭터당 색 5~7개 내외, 검은 윤곽선 없이 명암 2단으로만
  입체감 표현(이 시기 콘솔 게임은 보통 아웃라인이 얇거나 없음)

## 필드(밤의 도시) 사양

- 타일: 아스팔트 도로, 보도, 건물 외벽, 불 켜진 창문, 꺼진 창문 등 최소 구성
- 건물벽/창문 타일에는 충돌 박스(TileSet physics layer)를 걸어 통행 불가 처리
- 맵 크기는 이번 단계에서는 데모용으로 작게(20x15 타일 안팎)

## 이번 단계에서 하지 않는 것 (다음 단계 예정)

- 전투 시스템(랜덤 인카운터, 커맨드 배틀 UI, 스탯/스킬)
- 대화창 / 메시지 박스 시스템
- 메뉴(아이템, 장비, 세이브)
- NPC, 이벤트 트리거
- 사운드/BGM

이 항목들은 "독창적인 시스템·스토리"를 얹는 다음 단계에서 다룬다. 지금은 순수하게
"필드 위를 캐릭터가 걸어 다니는" 기초 골격까지만 완성한다.
