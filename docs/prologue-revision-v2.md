# 프롤로그 수정 v2

- 지정한 승리 대사 두 줄 삭제. 소년/소녀 나레이션과 마지막 말줄임표 수정. 재수입 도구에도 사용자 수정 적용.
- 시작 메뉴: 0–2.5초 야경 페이드 인, 2.7–4.7초 우측 상중단 로고 페이드 인, 5–6초 시작 버튼 등장. 기존 두 버튼 제거.
- 같은 새 옥상 이미지에서 왼쪽 건물 외벽을 따라 오프닝 카메라 하강.
- “로, 로고 띄워!” 대사에 진입하면 배경 암전. 대사를 넘기는 다음 입력에서 로고 즉시 표시. 자동 타이머/확대 등장 제거.
- 딱밤: 두 발의 보행 프레임, 감속 접근, 팔 들기, 손가락 준비, 팔 뻗기, 튕기기, 회수, 추흔의 움찔 반응, 대화 후 걸어서 복귀.
- 엔딩 그림: 전투 필드와 같은 돌바닥·차양 상점·가로등, 떨어져 선 두 동료. 발코니 구도 제거.

내장 이미지 생성 도구 사용. 아래는 프롬프트 요약:
- rooftop-v2.png: 첨부한 옥상 사진 구도, 왼쪽 사람 앉은 건물을 거리까지 확장한 연속 세로 배경. 우측 위 로고 여백, 별빛 밤 도시.
- ending-v2.png: 캐릭터 시트 및 실제 필드 화면 참고. 같은 돌바닥 거리의 뒤편에서 바라본 두 사람, 2–3m 간격, 금빛 연우 포인트, 로맨틱한 밀착/발코니/난간 제외.
- flick-v2-source.png: 기존 전투 그림체를 참고한 연우 4×2 포즈. 두 발 보행/정지/손 준비/손가락 튕기기/회수. 투명 배경.
- flick-v2.png: 동일 배율·고정 발 기준점으로 패킹한 런타임 시트. tools/pack_chapter_flick.gd 사용.
