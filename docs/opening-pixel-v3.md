# 오프닝 도트 배경 수정
사용자 요청: 옥상의 인물 제거, 오프닝 도트 아트.
시작 메뉴와 프롤로그의 배경을 rooftop-pixel-v3.png로 교체했다. 왼쪽 건물을 따라 내려가는 구도와 메뉴 등장 순서는 유지한다.
내장 이미지 생성 도구로 rooftop-v2.png를 참조하여 인물 전체 제거 및 청색/호박색 팔레트의 뚜렷한 픽셀 클러스터 도트 아트로 다시 생성했다. 인물·실루엣·텍스트를 배제하고 빈 옥상과 외벽/거리의 연속성을 요청했다.
배경은 최근접 필터와 정수 위치 스크롤로 표시한다. 로고와 엔딩 그림의 기존 필터는 유지한다.
