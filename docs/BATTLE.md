# 전투 구현 — 2026-10-21

사용자가 전달한 수정본 맵 시스템 기획서와 특수 스킬 목록을 현재 기준으로 삼는다. **타이머의 QTE는 삭제**했고, 일반 공격과 어쌔신 스텝은 실제 적 위치에 대응하는 타이밍 판정을 사용한다.

스킬 사용 중 임의로 만든 캐릭터 대사, 하품·먹는 소리, 모션 서술 문구는 모두 제거했다. 모션은 그림으로만 표현하고 스킬 이름·효과·QTE 안내·성공 횟수만 표시한다.

## 기본 흐름과 조작

추흔 → 연우 → 설아 → 위성 → 적 순으로 행동한다. 전투 불능인 유닛은 건너뛴다. 일반 필드 조우는 적 2~4마리이며, 꺼진 가로등 구역이 2개 이하로 남으면 3~5마리로 늘어난다. 보스는 1마리다. 필드가 두 번 어두워진 후 시계 방향 전환이 끝나면 전투 입력을 연다.

방향키/마우스 선택, Space/Enter(숫자패드 Enter 포함) 확인·타이밍 입력, Z 확인, Esc/X 메뉴 취소. 일반 공격은 선택 즉시 QTE를 시작한다. 회복만 아군 선택을 거치며, 비용은 실제 시전할 때 한 번 지불한다.

공격·수비·집중 행동으로 해당 스택을 최대 3개까지 쌓는다. 수비 자세는 라운드 동안 유지한다. 집중은 손앞에 푸른 기를 모으는 전용 동작이다. 미사용 스택은 **전투 종료 후에도 유지**된다. 기존 프로토타입의 전투 후 HP 회복과 패배 시 필드 입구 복귀를 유지한다.

## 위치 대응 타이밍과 어둠

- 적의 세로 위치가 QTE 바의 가로 위치를 정한다. 위쪽 적은 왼쪽, 아래쪽 적은 오른쪽이다. 적이 아래에 몰리면 판정선도 오른쪽에 몰린다.
- 적 배치는 전투 시작 시 무작위로 정한다. 일반 공격은 움직이는 커서가 적의 판정선에 있을 때 Space를 누르면 그 적을 공격한다. 빈 위치나 시간 초과는 MISS다.
- 일반 공격 바는 3.2초에 두 번 왕복한다. 적 위치선 ±0.045 범위에서 명중하며 기존 크리티컬 공격력 2배를 사용한다.
- 수비 QTE도 공격해 오는 적의 실제 위치를 사용한다. 성공은 무피해+반격, 일반 입력은 피해 절반, 시간 초과는 전부 피해다.
- 어둠에서는 적의 모습·HP와 미확인 판정선을 숨긴다. 성공한 적의 판정선은 해당 전투 동안 계속 보인다. **바와 이동 커서는 남아** 위치를 추측하여 입력할 수 있다. 내부 판정과 적 위치는 그대로다.
- 밝힘 시간은 메뉴나 QTE 중에도 실제 경과 시간으로 줄어든다. 마지막 2초에는 적과 미확인 판정선이 함께 서서히 사라진다. 밝힘은 해당 전투에만 적용하며 필드 가로등을 수리하지 않는다.

## 특수 스킬

| 캐릭터 / 스킬 | 비용 | 작동 |
|---|---|---|
| 추흔 / 타이머 | 공격 2, 집중 2 | QTE 없이 큰 전체 공격, 20초 밝힘 |
| 추흔 / 벼락 | 집중 1 | QTE 없이 작은 전체 공격, 10초 밝힘 |
| 연우 / 어쌔신 스텝 | 공격 3 | 위치 대응 QTE 4번, 귀환·하품 후 표식 피해 |
| 연우 / 회복 | 수비 1 | 아군 선택 후 회복, 대상별 음식 연출 |

### 타이머

도약 → 체인을 푸른 번개 창으로 변환 → 투척 → 창이 꽂힌 뒤 **1초 대기** → 적 전체 낙뢰와 화면 흔들림 → 착지. 선택 즉시 자동 진행하며 입력 성공/실패 분기는 없다. 창 자체는 연출이며 낙뢰 시 모든 적에게 한 번 피해를 준다. 낙뢰에 전멸해도 착지를 마친 후 승리를 처리한다.

현재 큰 피해는 공격력 5배(추흔 120)다. 낙뢰가 발생하는 순간부터 20초 밝힘을 센다.

### 벼락

제자리에서 체인을 창으로 바꾸고 위로 들어 번개를 부른다. 모든 적에게 공격력 1.5배(추흔 36) 피해를 주고 10초 동안 밝힌다. 대상 선택과 QTE가 없다.

### 어쌔신 스텝

체인→단검 변환 후 컷인 없이 곧바로 사라지고 **적 수와 관계없이 4번** QTE를 진행한다. 각 입력은 그 순간 커서가 가리킨 적의 실제 위치에 표식을 남긴다. 예를 들어 세 적을 차례대로 맞추면 2/1/1회, 보스만 맞추면 4회지만, 분배를 강제로 고정하지 않는다. 한 적에 네 번 집중하는 것도 가능하다.

각 바는 2.2초 동안 왼쪽에서 오른쪽으로 이동한다. 시퀀스 중에는 피해를 주지 않는다. 돌아와 하품한 뒤 성공 표식 하나당 공격력 6배(연우 168)를 해당 적에게 합산한다. 모두 실패하면 얼굴을 붉히고 발로 땅을 차며 끝난다. 복귀·하품·실패 반응은 일반 연우와 같은 전투 배율과 발 기준점을 사용한다. 실패 비용은 반환하지 않는다. 죽은 적 위치는 판정 대상에서 제외한다.

### 회복

아군을 선택하고 최대 HP의 40%를 회복한다. 자기 자신은 캔을 따서 마시고 버린 뒤 하품한다. 추흔 대상은 샌드위치를 던져 주고 추흔이 받아 먹는다. HP 상한을 넘지 않으며, 체력이 이미 가득 찬 대상은 시전하지 않고 선택 상태를 유지한다. 현재 회복은 HP 0인 동료에게도 적용되어 다시 행동할 수 있게 한다. 회복량과 전투 불능 대상 허용은 문서에 구체 수치/제한이 없어 정한 초기 구현이다.

## 보스

밝은 전투로 시작한다. HP가 50% 이하가 되면 한 번 어둠에 진입한다. 2라운드마다 위/아래로 위치를 바꾸고 타이밍 위치도 함께 바뀐다. 어둠 진입 뒤에도 타이머·벼락으로 잠시 밝힐 수 있다. 어둠 전환 HP와 이동 주기는 `boss_phase`에서 조정한다.

## 이미지와 구현

전투의 기존 도트 그림체와 일반 공격 애니메이션을 유지한다. 필드에만 새 하트골드 참고 스프라이트를 사용한다.

- `scripts/battle/battle_screen.gd`: 메뉴, 턴, 위치 판정, 어둠/밝힘, 보스.
- `scripts/battle/timer_skill.gd`: 자동 전체 낙뢰.
- `scripts/battle/assassin_skill.gd`: 4회 위치 QTE와 지연 피해.
- `scripts/battle/support_skill.gd`: 벼락, 음료수, 샌드위치 연출.
- `assets/sprites/battle/support-skills.png`: 이번에 내장 ImageGen으로 만든 12포즈 원본. 명시적인 영역과 발 기준점으로 읽는다. 프롬프트: `tools/support_skill_image_prompt.json`.
- 타이머는 기존 `chuheun-timer.png`와 `chuheun-timer-v2.png`, 어쌔신은 `yeonwoo-assassin.png`를 재사용한다. 눈 컷인 이미지는 로드하지 않는다.

수치 설정은 `data/battle_balance.json`에 있다. 타이머 20초/벼락 10초 밝힘과 스택 비용은 기획서 기준이다. 피해 배율·회복량·보스 전환 시점·판정 폭은 초기 조정값이다.

## 검사와 시연

Godot에 프로젝트를 불러와 F5로 실행한다. 필드에서 진행하거나 `tests/play_timer.gd`를 실행하면 스택이 준비된 특수 스킬 시연 전투를 열 수 있다.

`tests/battle_test.gd`, `tests/timer_test.gd`, `tests/encounter_revision_test.gd`, `tests/oct20_update_test.gd`, `tests/stack_carryover_test.gd`로 턴/입력, 자동 시전, 지연 피해, 어둠/밝힘, 스택 유지를 검증한다. `tests/preview_oct20.gd`는 실제 화면을 캡처한다.

새 캐릭터의 스킬·연출·수치와 가로등 영구 보호는 [4인 파티 확장](PARTY_EXPANSION.md)을 참고한다. 설아의 방패 전개 대사는 표시하지 않는다.
