# 4인 파티 확장 — 2026-10-21

## 확정 자료

사용자 제공 이미지 6장은 `assets/references/`에 원본 그대로 복사했다. 강설아는 검은 단발의 겁 많은 여자아이이며, 크로노 체인을 몸을 가리는 커다란 방패로 변화시킨다. 장위성은 후드가 머리와 눈을 가리는 마법사이며, 끊어진 은색 원형 장식과 푸른 구슬이 달린 지팡이를 사용한다. 추흔의 원뿔 창, 연우의 단검 참고도 함께 보관한다.

이번 스킬표 말미의 “방패로 변화시킨 뒤 무겁게 들고 적을 후려침”은 설아의 크게 휘두르기 동작으로 해석했다. 문서의 과거 조명 시간보다 사용자가 이번 채팅에서 지정한 벼락 10초 / 타이머 20초를 우선한다.

## 전투 규칙

| 캐릭터 / 스킬 | 비용 | 효과 |
|---|---|---|
| 강설아 / 방패 전개 | 수비 2 | 발동 후 공격 유도. 다음 1번의 자신의 행동을 자동 수비로 대체하고 그 라운드의 적 행동 종료 후 해제. 이 동안 스택 획득 없음. 사용자 확인에 따라 세 효과 모두 1턴으로 통일. 전투 불능이면 유도 중단. |
| 강설아 / 크게 휘두르기 | 집중 1 | 기본 공격과 같은 위치 대응 QTE로 적 한 명을 강타. 실패해도 집중 비용은 지불하며 공격 스택은 획득하지 않음. |
| 장위성 / 맵 밝히기 | 집중 1 | 지팡이 변화와 구슬 발광 후 현재 전투를 20초 밝힘. QTE 없음. 턴은 사용함. 가로등 수리와 별개의 전투 조명 효과. |

| 장위성 / 바인드 | 공격 1·집중 1 | 전체 적 위치선을 표시하는 QTE. 성공한 일반 적은 다음 2회 행동 봉쇄. 보스는 3왕복에서 각 1회씩 모두 성공해야 봉쇄. |

스킬표에 없는 초기 조정값: 설아 HP 180 / 공격력 22, 위성 HP 95 / 공격력 26. 크게 휘두르기는 기본 QTE 피해의 3배(명중 132). `data/battle_balance.json`에서 조정 가능하다.

추흔 → 연우 → 설아 → 위성 → 적 순으로 행동하고 전투 불능 캐릭터는 건너뛴다. 회복은 네 명 모두 선택 가능하다. 기존 규칙처럼 HP 0 동료도 회복할 수 있다. 공격/수비/집중 스택은 각각 최대 3이며 승패와 관계없이 다음 전투로 이월한다. 방패 전개와 일반 방어 자세는 전투 종료 시 해제한다.

일반 적은 3~5마리, 보스는 1마리. 최대 다섯 적의 모습과 체력 표시를 분리 배치하고 위치 QTE는 실제 Y좌표를 따른다. 수동 점등한 가로등은 필드 상태가 유지되는 동안 영구 보호된다. 게임 전체 저장 기능은 기존 프로젝트에 없으므로 앱 재시작 시에는 새 게임이다.

## 후속 조정 — 배치, 방패, 빛 구역 순찰

- 전투는 사용자 배치도에 따라 앞줄 위 연우·아래 추흔, 뒷줄 중간 설아·아래 위성으로 배치한다. 방패 전개 목적지는 앞줄보다 오른쪽이며 연우와 설아 사이 높이인 초록 원 위치다. 설아는 다른 캐릭터보다 12% 작게 그린다. 필드 시작/워프 때는 통행 가능한 직선으로 정렬하고, 이동 시에는 앞사람의 경로를 따른다.
- 위성의 필드 정지 프레임 높이를 추흔·연우의 방향별 높이에 맞췄다(앞 53px, 왼쪽 55px, 오른쪽 58px, 뒤 53px). 걷기 프레임에도 같은 방향별 배율을 적용한다.
- `seola-shield-source.png`와 `seola-shield.png`에 오른쪽 방패 자세와 체인 수비/이동/변형/놀람/도주 9개 프레임을 추가했다. 일반 수비에는 체인만 사용한다. 일반 집중에서도 무기를 변화시키지 않는다.
- 방패 전개: 0.65초간 초록 원 위치로 이동 → 양손으로 체인을 머리 위에 든 상태에서 2초 변형(체인만 푸르게 빛난 뒤 머리 위 방패로 변화) → 눈을 감고 3.05초 시점에 내려찍으며 효과 적용 → 3.85초까지 숨는 동작. 유지 중에는 방패 뒤에서 떤다. 대사는 없다.
- 설아의 전투 20프레임 전체를 추흔·연우의 원본 시트와 같은 정상 신체 비율·세밀한 도트 그림체로 교체했다. 작은 키만 유지하며 SD 비율은 사용하지 않는다. `seola-cohesive-source.png`에서 기본·방패·머리 위 변형 시트 3장을 생성한다. 내장 ImageGen 프롬프트는 `tools/seola_cohesive_prompt.json`, 추출은 `tools/seola_atlas_baker.gd`에 보관한다.
- 지속 종료: 0.8초간 방패를 체인으로 복귀 → 0.6초 놀람 → 0.85초간 원래 자리로 도망. 모두 끝난 뒤 다음 라운드가 시작된다.
- 현재 밝은 구역의 절반(홀수면 올림)을 선택해 구역당 1~2마리가 무작위 순찰한다. 순찰자는 구역 밖으로 도망가거나 가로등을 파괴하지 않는다. 어둠 생성/도주는 유지하고, 가로등 파괴는 프로토타입에서 비활성화한다. 30초마다 빈 순찰 인원을 보충하며 전투 중에는 멈춘다. 점등 상태가 바뀌면 선정 구역 수를 갱신한다.
- `tests/shield_patrol_test.gd`에서 전개 효과 적용 시점, 유지 위치, 종료 후 턴 복귀, 순찰 분포/이동/가로등 보호/보충을 검사한다.

## 위치 판정과 최신 스킬 변경

- 전투 캐릭터 배율을 0.48에서 0.64로 확대하고 앞뒤 열 간격은 133에서 115로 좁혔다. 상태 표시는 작은 체력 바와 수치로 정리했다.
- 공격·수비·어쌔신/바인드의 위치 판정에 성공한 적의 위치선을 전투가 끝날 때까지 기억한다. 밝힘 효과가 끝나도 기억한 선은 남고 적 본체는 계속 숨겨진다. 보스 이동 시 기억한 선도 새 위치를 따른다. 새 전투에서는 초기화한다.
- 수비는 현재 공격 중인 적의 실제 위치선 하나를 사용한다. 해당 선 명중 시 무피해 반격, 나머지 입력은 피해 절반, 시간 초과는 전부 피해다.
- 크게 휘두르기: 머리 위 체인→방패 변화와 무겁게 들기 → 위치 QTE → 목표로 점프 → 0.7초 착지 시 피해 → 두리번/놀람 → 체인을 들고 원위치로 도주.
- 바인드: 지팡이에 집중 → 전체 위치선 QTE → 지팡이 내려찍기 → 성공 대상에게 사슬 표시. 일반 QTE는 여러 적을 지정할 수 있으며 같은 적 중복 입력은 중복 적용하지 않는다. 보스는 왕복당 첫 입력 하나만 인정하며 한 번이라도 실패/누락하면 봉쇄되지 않는다. 봉쇄 중에는 보스 위치 이동도 멈춘다.
- 미니맵은 실제 타일 지형·통로·가로등·플레이어 좌표를 2:1 비율로 축소한다. 점등 변경 시 배경을 갱신하고 플레이어 위치는 실시간 갱신한다.
- 최신 스킬표의 타이머 15초 표기보다 앞서 사용자가 직접 정한 20초를 유지한다. 벼락은 10초다.
- `tests/marker_bind_test.gd`는 기억 지속/적별 분리/보스 이동/새 전투 초기화, 위치 방어, 다중 바인드·보스 3왕복·실패·2회 행동 봉쇄, 미니맵 좌표를 검증한다.
