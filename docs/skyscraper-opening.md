# 마천루 오프닝과 빠른 메뉴 표시

- 메뉴 등장 도중 Enter/KP Enter를 누르면 야경·로고·시작 버튼을 즉시 표시한다. 그 입력으로 게임까지 시작하지 않으며 다음 입력으로 시작한다. 키 자동 반복은 무시한다.
- 인물 없는 도트 마천루 옥상으로 교체했다. 메뉴와 프롤로그 시작 카메라는 같은 위치다.
- 프롤로그 하강 속도는 초반22px/s, 가속180→620→2200px/s. 위치는 대사 지점에 도착해서 멈추지 않고 계속 누적한다.
- 외벽 구간으로 부드럽게 전환하여 수직 반복하며, 48px 겹침으로 연결부를 섞는다. 지면 이미지와 건물 입구가 없는 외벽을 사용한다. 빠른 구간에는 세로 속도선을 추가한다.
- “밤은…” 암전 시 외벽도 함께 숨긴다.
- 실제 키 이벤트로 첫 Enter 표시/두 번째 Enter 시작을 검사했다. 30초 급하강 시뮬레이션에서 6만 픽셀 이상 계속 이동하고 바닥 없이 반복되는 것을 검사했다.

이미지는 내장 image_gen으로 생성했다.
