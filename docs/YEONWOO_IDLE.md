# 연우 전투 대기: 작은 발끝 까딱임

졸음 연기를 넣기 전의 원본 `assets/sprites/yeonwoo-toe-idle/toe-tap.png`로 복귀했다. 새 이미지를 생성하지 않고 기존의 작은 움직임을 사용한다.

1.8초 주기 안에서 발을 내려놓은 채 1.2초 쉬고, 나머지 0.6초 동안 1 → 2 → 1 포즈로 발끝을 조금 들었다 내린다. 높이 드는 3·4번 포즈는 사용하지 않는다. 상체를 추가로 흔들거나 이동시키지 않는다.

졸린 눈 깜빡임, 고개 숙임, 하품, 사슬 정리는 대기에서 제외했다. 기존 공동 대기 순서는 유지하되 연우 차례에도 같은 작은 발끝 모션을 지속하여 추흔의 연출 간격이 달라지지 않게 했다. 공격·수비·피격·특수기·필드 체인은 유지한다.

- 실제 전투 미리보기: `art-reviews/yeonwoo-gentle-idle/yeonwoo-idle.gif`
- 미리보기 생성: `tests/preview_yeonwoo_gentle_idle.gd`
- 검사: 원본 자산 연결, 작은 포즈만 사용, 쉬는 시간 비율, 프레임 잘림 및 지지발 고정, 기존 전투 흐름.

이전 성격 연출과 과장된 발끝 모션의 파일은 보관하지만 실행 중에는 사용하지 않는다.
