## 실행

기존 시작 메뉴의 **프롤로그 실행**으로 시작한다. **튜토리얼 실행**은 기존 게임을 연다. F10으로 메뉴로 돌아간다. 대사는 Space / Enter / 클릭으로 넘긴다. 첫 입력은 타이핑을 완성하고 다음 입력은 다음 대사로 이동한다. 특정 키를 요구하는 안내에서는 해당 키를 사용한다.

## 체인과 기존 작업 유지

- 프롤로그와 기존 필드 모두 추흔의 현재 칸을 중심으로 가로·세로 ±2칸, 총 5×5 안의 적을 판정한다. 모서리와 뒤쪽도 포함한다.
- 후보가 여럿이면 무작위 한 적만 락온한다. 범위 안에 남아 있는 동안 대상이 바뀌지 않는다.
- Enter로 기존 추흔의 전용 체인 동작을 재생하고 손목에서 대상까지 호밍 체인을 연결한다. 맞은 적과 아군 선제 전투에 돌입한다.
- 기존 필드의 어둠 속 숨은 적 규칙은 유지한다. T 입력도 호환용으로 남아 있지만 화면 안내는 Enter를 사용한다.
- 기존 걷기·전투·작은 발 까딱임 프레임은 유지한다. 연우의 분홍 계열 포인트만 런타임 색상 셰이더로 금빛으로 바꾼다. 새 포즈는 이번 스크립트의 이벤트에만 사용한다.
- 각 튜토리얼 전투 사이에는 체력을 회복하고 스택은 이어간다. 패배하면 해당 전투를 다시 시작한다. 일반 게임 파티 수치는 덮어쓰지 않는다.
